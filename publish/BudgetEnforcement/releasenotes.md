# Release Notes

## 1.0.0
- Initial release.
- Deploys an Azure Function App (Powershell) to enforce budget constraints.
- Supports stopping or deleting resources based on 'Loome-Budget Status : Exceeded' tag.
- Configurable frequency (1, 2, 4, 8, 12, 24 hours).
- Supports custom PowerShell script execution.
